## Intel ECM diagnostic preview · November 5, 2026

0.2.29-ecm-preview.2 adopts the Android normal Full-session rule for existing
Mac USB bindings (Nano, Chipsoft and MDI). An old limited-mode preference no
longer changes Connect and start. Mac MX+ retains its existing limited binding;
this scoped preview makes no new Bluetooth claim. Collection remains a separate
workflow. Processed-card continuation explicitly offers Resume in Full session,
with existing identity, cleanup, consent and import checks preserved.

Nano refusals now carry the same fixed policy classification as other adapters.
The shared desktop report collector retains a whitelisted diagnostic summary in
its existing message field. Passive intent/queue counters do not prove wire
transmission, ECU acceptance, durable writes or a complete Add phase. Raw errors,
vehicle/security bytes and local paths remain private. Exact package, installed
and physical evidence remain separate. No ECM Add/Remove qualification or prior
failure diagnosis follows from these changes.
